## 读音与字形训练

- 每天练昨天新背的全部词，再随机加入10个更早背过的词，不设30词上限。昨天新背25词，今天就是25＋10＝35词。历史词不足10个时按实际数量安排，当日新背词次日参加。
- 每天的名单固定保存，刷新、换页、答完或导入备份不会自动换一批；错题重练不另占名额。当天答对就停止出题，混合复习中的读音题也共用这个名单；仍不受课次和优先级筛选限制。
- 看汉字选假名、看假名选日语汉字随机混合；纯假名词使用中文提示选假名。
- 同一个词的两种题型共用跨天连续答对计数。当天选对一次后不再出读音题，未满5次则次日0点再出现；答错练到答对，订正只算今日完成，不增加达标次数。不同日期首次作答连续正确5次后转低频抽查：7天后再问；继续答对后依次延长到14天、30天，此后保持30天。答错一次归零，恢复正常训练频率，并加入次日复习，其他词不受影响。
- 假名干扰项只修改目标读音中的长音、促音、拗音、清浊音或相近假名，不拿无关词充当选项。
- 汉字干扰项保留词形结构并改动形近字；避开已知合法异体写法。同形异读词保留词义，汉字题优先使用短语语境。
- 正确答案、解释与联合记忆只在答题后揭晓。点选答案后，无论对错都自动朗读目标词的正确读音；选答案前不播放。

## 狂刷模式

左侧「狂刷模式」覆盖全部已背词，不受每日数量、课次或优先级限制。全部为选择题，随机切换汉字选假名与假名选汉字，沿用相近假名、形近汉字干扰项；纯假名词仍以中文提示选假名。选答案前静音，作答后自动朗读正确读音。

每词在狂刷中连续答对5次就退出本模式，错一次归零。普通读音训练已经跨天连对5次的词也会跳过；以后在普通读音训练答错，或词卡标记不熟，会重新加入。狂刷计数独立于每日读音训练的跨天计数，常规间隔复习继续安排。狂刷错误计入累计读音错误与次日复习，不占每日新词、普通复习或固定读音名单的名额。

有错误或标记不熟记录的词优先，同组内保持随机；已有保存队列也立即应用错题优先。按随机轮次持续练习，每轮每词一次，整轮结束后重新打乱；有多个待练词时避免轮次交界相邻重复，词量充足时至少穿插6道其他题。仅剩一个待练词时继续练该词。随机队列、轮次、每词连续答对次数均保存到进度与备份。每题小字显示「累计错 X 次」，统计普通读音训练与狂刷的全部错误，答对不清零。

## 复习与进度

新词仍在所选学习范围内随机抽取。每日复习不受新词筛选限制，按以下顺序选择，去重后取每日上限（如50或100词）：

1. 昨天新背的词，以及昨天答错或点过「再学一次／还不太熟」的词；昨日错得多的优先，即使昨天后来订正也保留。
2. 其余到期词与未完成复习，逾期较久者优先，再按累计错误次数排序。
3. 剩余额度按累计错误排名补充仍在短间隔阶段（小于7天）、尚未稳定的错词。已稳定且未到期的熟词不为凑数加入；超过每日上限的到期词保留，次日继续安排。

首次点「认识了」默认次日复查；到期后在没有当天错误的情况下成功回忆，逐步使用3、7、14、30、60天的间隔。这些数值是距本次成功回忆之后的间隔，不是距初学日的固定日期，也不是研究证明的唯一最优日程。当天出错后订正不升级，次日仍复查；提前加练既不升级，也不推迟原到期日。按钮直接显示按当前表现预计的下次复习日期。

累计错误包含读音、狂刷答错以及词卡的两种不熟按钮，每次一次，不重复计算读音内部记账；答对不清零。累计总数、失败日期和每日名单随进度与备份保存。当天进入复习后固定名单；调整数量时保留已完成词，再安排其他候选词。

研究依据：Cepeda等（2008），https://doi.org/10.1111/j.1467-9280.2008.02209.x ，间隔效果取决于目标保持时长；Karpicke与Roediger（2008），https://doi.org/10.1126/science.1152408 ，主动提取对外语词汇长期记忆有帮助；Murre与Dros（2015），https://doi.org/10.1371/journal.pone.0120644 ，遗忘曲线复现。研究支持分散练习和提取，不提供适用于所有人的固定日历；本站默认阶梯是实现选择。

左侧「极易错」有两个独立入口：读音题累计错至少5次（两种题型合并），或同一词在单词卡里连续点5次「再学一次」。词卡点「认识了」或「还不太熟」会打断当前连点次数；曾达到门槛的最高连点记录继续保留。读音和词卡计数分别显示，旧日志会迁移；复习读音题的内部记账不计作一次词卡选择。

单词卡选择「再学一次」或「还不太熟」后，隔1～2个其他词重现，不限重复次数，直到选择「认识了」；只剩一个待巩固词时直接继续练。本组进度只按「认识了」计数。待巩固词在刷新、重新进入或导入备份后保留，不受每日数量上限截断。点「认识了」完成当天练习，并按实际成功回忆与失败记录安排下次复习。原间隔数据仍保留，读音低频抽查规则不变。读音计数和间隔复习独立保存。词条ID保持稳定，更新保留旧进度；旧记录按日期去重后迁移，当天有错不算达标；保留背词进度、收藏与累计错误，避免把同一天的5次正确当成跨天5次。

新版使用独立的本地存储键，首次自动迁移旧版记录，避免尚未刷新的旧标签页覆盖新版词条。JSON备份导出/导入保留读音计数、今日训练名单和词卡连点记录；词表可下载CSV。跨设备需要手动迁移备份。朗读依赖系统安装的日语合成语音。

## 自他动词与学习时长

782项动词（含サ变名词）按词形、读音及词义标注自动词、他动词、自他动词；「楽しめる」单列可能形。详情列出已编录的双向对应词及假名、中文，词库内的对应词可点开；词库外的对应词仅作为说明，不产生新学习记录。分类数据参考JMdict/EDICT，修正同音词、异读和教材词义范围；「開く（あく）」为自动词，「開ける（あける）」为他动词，「開く（ひらく）」自他两用。

学习记录显示北京时间当前年月日和月历，每天按小时显示累计学习时长；可以前后切换月份。仅在学习页面处于前台时计时，每20秒保存，后台或连续2分钟无操作暂停；离开学习页面时保存。时长按北京时间零点分到不同日期，并随JSON备份导入导出；旧版本没有时长的日期显示「未记录」，不推算。普通学习日志和收藏保留。

学习日历中，今天及过去日期记录的时长不足5分钟时标红，达到5分钟恢复正常；未来日期不标红。没有计时记录的日期仍显示「未记录」，按不足5分钟着色。

学习日历同时显示每天的时长、新背词数和错词数。新背按首次学习的单词去重，复习不重复算新词；日历的错词数仅统计普通「读音训练」答错的单词，同一词同一天只算一个错词，订正后仍保留；不包含词卡点不熟或狂刷模式，累计错误排名的计数规则保持不变。每日词数汇总随备份保存，不因详细日志截断而消失；旧版本按尚存日志和首次学习日期补齐，已丢失的历史明细无法恢复。
