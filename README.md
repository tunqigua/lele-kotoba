# 拾词 · 语言考试

日语词汇学习网站：[打开网站](https://tunqigua.github.io/lele-kotoba/)。

以电脑学习为主的静态日语词汇网站。界面保留导航、词卡、训练和学习计划，去掉装饰性英文与宣传面板。

## 词库

共1028项。原词表第189—198页为精选，新增12页（第198—209页）逐项录入可辨认词条，合并重复出处；同音异义、同形异读分别保留。14项仍为参考补充词。页码按原词表、新增词表区分；不猜测无法辨认的课次。

A优先掌握295项，B重点巩固637项，C阅读识记96项。分级依据基础程度、常用搭配和活用迁移价值；参考卷只用于判断题型，不按单套卷出现频率预测考试概率。

227组联合记忆短语覆盖273项词条，带完整假名、中文和可点击的关联词。日语释义取常用义，并非穷尽所有词典义项。

## 读音与字形训练

- 从所有已背词中随机抽取，不受每日上限、课次或优先级筛选限制。
- 看汉字选假名、看假名选日语汉字随机混合；纯假名词使用中文提示选假名。
- 同一个词的两种题型共用跨天连续答对计数。当天选对一次后不再出读音题，未满5次则次日0点再出现；答错练到答对，订正只算今日完成，不增加达标次数。不同日期首次作答连续正确5次后转低频抽查：7天后再问；继续答对后依次延长到14天、30天，此后保持30天。答错一次归零，恢复正常训练频率，并加入次日复习，其他词不受影响。
- 假名干扰项只修改目标读音中的长音、促音、拗音、清浊音或相近假名，不拿无关词充当选项。
- 汉字干扰项保留词形结构并改动形近字；避开已知合法异体写法。同形异读词保留词义，汉字题优先使用短语语境。
- 正确答案、解释与联合记忆只在答题后揭晓。

## 复习与进度

默认将现有词库混合随机抽取：先打乱全部符合范围的未学词，再取当天数量，不按五十音、课次、来源或A/B/C分组顺序背诵。「再学10个」同样从完整未学池随机抽取。复习仅包含已学且到期或未完成的词，题目顺序打乱；逾期较久的词仍优先入选，未完成词不会漏掉。自行选择课次或优先级后，也会在该范围内随机抽取。

复习统一在到期日北京时间0点解锁。前一天读音答错、点过「还不太熟」或「再学一次」的词也会在次日加入，即使当天后来答对。网页一直打开或从后台恢复时会自动更新，不要求手动刷新。旧版按具体时刻到期的记录迁移为对应日期0点，保留现有进度。

「间隔复习」将本组到期词随机显示为单词卡或读音题，不再分两个标签；两种读音题继续随机。答对或点「认识了」完成本轮，答错或不熟则隔1～2词再现。已经连续答对5次的词在读音抽查到期前继续使用单词卡；到期后会重新安排读音题，即使词卡尚未到期。

左侧「极易错」收录读音题累计答错至少5次的词，选假名和选汉字合并计数。答对不清除累计错误数；单词卡的不熟悉次数不计入这个门槛。旧读音错误日志自动迁移，计数随备份保留。

单词卡选择「再学一次」或「还不太熟」后，隔1～2个其他词重现，不限重复次数，直到选择「认识了」；只剩一个待巩固词时直接继续练。本组进度只按「认识了」计数。待巩固词在刷新、重新进入或导入备份后保留，不受每日数量上限截断。点「认识了」后，再按1、3、7、14、30、60天安排复习。读音计数和间隔复习独立保存。词条ID保持稳定，更新保留旧进度；旧记录按日期去重后迁移，当天有错不算达标；保留背词进度、收藏与累计错误，避免把同一天的5次正确当成跨天5次。

新版使用独立的本地存储键，首次自动迁移旧版记录，避免尚未刷新的旧标签页覆盖新版词条。JSON备份导出/导入保留读音计数；词表可下载CSV。跨设备需要手动迁移备份。朗读依赖系统安装的日语合成语音。

## 本地运行与检查

无需依赖安装和构建。用静态服务器托管 `dist/`，或打开 `dist/index.html` 体验；正式学习建议使用固定HTTPS地址。

```bash
python3 tools/make-data.py
node --check dist/app.js
node --check dist/quiz.js
node --test tests/*.test.cjs
node tests/app-smoke.cjs
```

检查覆盖北京时间零点与跨年更新、前日错误入队、混合复习、累计五错归档、旧词条ID与进度迁移、所有词的干扰选项、随机题型、仅抽已学词、错答归零、5次转低频、7/14/30天抽查、错答恢复、题目无答案泄露、短语链接及复习逻辑。UI检查采用DOM替身，不等同于实机浏览器显示检查。

`tools/additional.tsv` 保留新增照片的逐页录入；`tools/enrich.py` 维护联合记忆与人工校核的易混选项。改动词库后重新生成 `dist/data.js`。
