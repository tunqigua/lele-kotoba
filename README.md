# 拾词 · 语言考试

日语词汇学习网站：[打开网站](https://tunqigua.github.io/lele-kotoba/)。

以电脑学习为主的静态日语词汇网站。界面保留导航、词卡、训练和学习计划，去掉装饰性英文与宣传面板。

## 词库

共1028项。原词表第189—198页为精选，新增12页（第198—209页）逐项录入可辨认词条，合并重复出处；同音异义、同形异读分别保留。14项仍为参考补充词。页码按原词表、新增词表区分；不猜测无法辨认的课次。

A优先掌握295项，B重点巩固637项，C阅读识记96项。分级依据基础程度、常用搭配和活用迁移价值；参考卷只用于判断题型，不按单套卷出现频率预测考试概率。

227组联合记忆短语覆盖273项词条，带完整假名、中文和可点击的关联词。日语释义取常用义，并非穷尽所有词典义项。

## 读音与字形训练

- 从所有已背词中随机抽取，不受每日上限、课次或优先级筛选限制。
- 看汉字选假名、看假名选日语汉字随机混合；纯假名词使用中文提示选假名。
- 同一个词的两种题型共用连续答对计数。连对5次后退出训练；答错一次，该词归零，其他词不受影响。
- 假名干扰项只修改目标读音中的长音、促音、拗音、清浊音或相近假名，不拿无关词充当选项。
- 汉字干扰项保留词形结构并改动形近字；避开已知合法异体写法。同形异读词保留词义，汉字题优先使用短语语境。
- 正确答案、解释与联合记忆只在答题后揭晓。

## 复习与进度

单词卡按1、3、7、14、30、60天安排复习。读音计数和间隔复习独立保存。词条ID保持稳定，更新保留旧进度；旧记录按连续答对、遇错归零迁移。

新版使用独立的本地存储键，首次自动迁移旧版记录，避免尚未刷新的旧标签页覆盖新版词条。JSON备份导出/导入保留读音计数；词表可下载CSV。跨设备需要手动迁移备份。朗读依赖系统安装的日语合成语音。

## 本地运行与检查

无需依赖安装和构建。用静态服务器托管 `dist/`，或打开 `dist/index.html` 体验；正式学习建议使用固定HTTPS地址。

```bash
python3 tools/make-data.py
node --check dist/app.js
node --check dist/quiz.js
node --test tests/*.test.cjs
node tests/app-smoke.cjs
```

检查覆盖旧词条ID与进度迁移、所有词的干扰选项、随机题型、仅抽已学词、错答归零、5次退出、题目无答案泄露、短语链接及复习逻辑。UI检查采用DOM替身，不等同于实机浏览器显示检查。

`tools/additional.tsv` 保留新增照片的逐页录入；`tools/enrich.py` 维护联合记忆与人工校核的易混选项。改动词库后重新生成 `dist/data.js`。

GitHub Pages工作流已准备在 `.github/workflows/pages.yml`，托管目录为 `dist/`。推送到 `main` 分支后自动检查并发布。学习记录保存在当前浏览器，切换网址前请先导出备份，在新网址导入。
